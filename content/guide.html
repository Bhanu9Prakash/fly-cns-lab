Start with one intact run, make one change, and compare the response. This guide explains the controls and what to watch in each part of the lab.

Open the arenaRead the introduction

Your first flight, in five minutes

  1. Open a clean starting point. Use this intact arena setup. Leave Object approaching head-on, Intact circuit, visual input on, and motor output connected.
  2. Press Start experiment. The sphere approaches. Watch the fly leave the floor, move, and return. The model runs for 12 seconds; at the default 0.35× playback, a full run takes about 34 seconds to display.
  3. Pause early. Use Pause, then Step 20 ms. Look at Inside the loop: visual channels, DNp01, launch neurons, wing power, and steering readouts each show their current simulated activity.
  4. Inspect a population. Click a readout row, select a dot in the neural graph, or use Inspect any population. Read its activity, represented neuron count, transmitter label, and retained input fraction.
  5. Remove wing power and rerun. Choose Silence DLM / DVM · wing power. The setting starts a fresh run. Press Start experiment again and compare the jump, horizontal speed, and wing-power trace.
Change one thing at a time. Environment, intervention, visual input, motor connection, and lift-strength changes reset the run. Camera and playback-speed changes preserve it. Export a run before changing its settings if you want to retain it.

How to read the screen

The arena

The green trail records the fly’s calculated trajectory. Green force arrows indicate lift command and amber arrows indicate thrust command. Their lengths are qualitative. Grid spacing is 2 au. The target’s path is prescribed and it exerts no contact force on the fly; the fly’s path follows the motor readouts and body rules.

Height above floor is measured relative to the body’s resting height. Horizontal speed uses motion along the floor plane. Wing power command is the transformed motor readout sent to the body; 50% is neither a measured muscle force nor a probability of flight. Assumed yaw command controls the modeled rate of turning.

Inside the loop

Each dot is a population. Colors use a logarithmic activity scale so small signals remain visible. Brightness differences are therefore not proportional to activity differences. Selected links are highlighted; the layout groups populations by role and does not show their physical positions in the brain. All {{ARENA_EDGES}} included links are simulated, while 450 strong links and selected connections are drawn.

Readout rows summarize useful populations. They do not claim that each row connects directly to the next. Activity values are bounded between 0 and 1. The exact numbers are more useful than color when comparing two runs.

What the fly sees

The disk illustrates the target’s bearing and angular size from the current pose. Numeric left/right drives show the last applied 20 ms sensory step. A rapidly changing pose can therefore produce a small difference between the current view and those values. The model uses geometry to produce features; it does not process this canvas as an image.

From input to movement

The three traces show visual drive, wing motor activity, and altitude. Each has its own scale. Similar heights in different rows do not imply equal quantities. The time cursor keeps the graph, body, and readouts aligned with the frame you are reviewing.

What happened

The event list marks modeled input onset, threshold-triggered launch, leaving the floor, and returning to it. These timestamps are model results. They are not experimentally measured reaction times.

Using the circuit experiment

Open Circuit experiment when you want a prescribed input without body feedback. It uses the original {{CIRCUIT_NODES}}-population graph. Its settings are independent of the arena.

  1. Select a stimulus. Looming drives LC4/LPLC2; motion channel A drives T4a/T5a; motion channel B drives T4b/T5b. No stimulus supplies zero external input.
  2. Choose Both sides, Left, or Right. Input strength changes external drive; connection gain scales propagation through the included graph.
  3. Press Run stimulus. The default pulse occupies 60–240 model ms within a 600 ms run. Pause or use the timeline to examine it.
  4. Inspect or silence. Search a type, select a population, and press Silence this population. The shortcut silences both DNp01 populations; Restore all removes interventions.
  5. Read the comparison. Solid curves show the current run. When populations are silenced, dashed curves retain the intact comparison. The table reports peak activity over the complete run, which can differ from the value at your current frame.

Under Model assumptions, signed activity uses transmitter-based signs. Unsigned structural spread makes every included sign positive. The glutamate control tests an inhibitory, excitatory, or omitted effect. These controls test model sensitivity; changing a global sign does not identify the actual receptors of a neuron.

Saving and reproducing experiments

Export run in the arena downloads a JSON file containing settings, body-adapter coefficients, node identities, recorded neural activity, poses, events, and data provenance. It exports the recorded run, including any recorded frames beyond a currently selected review time.

In the circuit experiment, Download results CSV exports population summaries, and Export experiment includes trajectories and settings. Under Model & data, you can download the prepared graphs and full-CNS comparison. The GitHub repository contains the code and Python reproduction instructions.

Runs are not stored as a persistent experiment collection. Download a result you want to keep before leaving or resetting the page. Reading pages and lab links do not require you to supply an API key.

If something looks unexpected

The fly does not move
Check visual input, motor connection, intervention, and whether the target is stationary. For a known baseline, open the intact setup and press Start.
The target passes through the fly
It is a visual stimulus with no collision force. Contact avoidance is not an implemented task.
I see a flat position marker
The app uses a labeled top-down fallback when WebGL or the anatomical asset is unavailable. Numeric simulation and readouts can still run.
A population stays dark
It may receive little drive, be inhibited, be silenced, or lack important inputs in the cropped graph. Darkness alone does not establish irrelevance in a real fly.
The result differs between tabs
The graphs, input protocols, duration, and feedback differ. Compare like-for-like settings within the same mode.
Changing a setting sent the fly back to the floor
That starts a new experiment from rest. It is not an intervention applied midway through the previous flight.
